menu_book Non-Technical Judge Quick Reference Guide

Simple explanations for key SRE intelligence concepts

Remove Repeated Alerts (Deduplication)

When monitoring tools send 10 alerts in 10 seconds for the same issue, the system merges them into 1 single event so on-call engineers don't get spammed.

Group Related Alerts (Correlation)

When a database fails and causes 5 downstream web APIs to trigger alerts, the system bundles all 5 alerts under 1 primary incident instead of creating 5 separate alarms.

Prevent Unnecessary Notifications (Suppression)

Low-impact test warnings, non-production metric jitters, and rapid repetitive flashes are silenced automatically while logging an audit trail.

Average Time to Acknowledge (MTTA)

How long it takes an engineer to click 'Acknowledge' after receiving an alert. Reducing noise directly speeds this up from 45 minutes to under 3 minutes.

Average Time to Resolve (MTTR)

The total duration from incident detection until complete mitigation. Having root-cause context immediately available saves critical minutes.

Actionable Signal Ratio

The percentage of delivered messages that genuinely required engineer intervention. Alert Fatigue Buster drives this from 3% to over 95%.
